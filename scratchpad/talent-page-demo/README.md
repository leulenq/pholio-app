# /talent scrollytelling demo

A standalone concept for the marketing site's `/talent` page: one talent's set followed through shoot, freshness, guided capture, stats, comp card, Pholio ID, the market's shot lists, the seven-page submission, the review window, the ledger, Intel, likeness permissions and pricing.

- `pholio-talent.html` — single file, images inlined. Open in a browser and scroll.
- `index.html` + `img2/` — editable source (same page, images as files).

Libraries load from CDNs: GSAP 3.12.5 + ScrollTrigger (cdnjs), Lenis 1.1.13 (unpkg), Google Fonts.

Scenes marked "In development" show planned features (guided capture, Pholio ID, who-sees-what preview).

Photography: sammy swae on Unsplash (Unsplash License), used for this prototype only. Demo identity: Elara Keats (`elara-k`). House names are placeholders by city and board; shot lists and read-clock timing are illustrative.
