Cascade

Load order is the contract.

The React SPA builds its cascade from token layers first, then global primitives, then utilities, then Tailwind. Component CSS is imported by JSX and should stay local to the component that owns it.

client/src
1main.jsx -> styles/agency-tokens.cssAgency token layer: --ag-* and legacy --agency-* aliases.
2main.jsx -> styles/agency-dark-overrides.cssScoped Tailwind-to-token remaps inside .ag.
3index.css -> styles/tokens.cssTalent and shared token layer: --color-*, spacing, radii, shadows.
4index.css -> styles/global.cssBase resets, document rules, focus rings, forms, buttons, tables.
5index.css -> styles/utilities.cssLayout helpers, gold Tailwind shims, shared Pholio presentation classes.
6index.css -> tailwindcss + @themeTailwind utility layer with Pholio gold and display font extensions.

File-by-file

Each stylesheet has a narrow job.

The global stylesheet should stay small and boring. Tokens define raw values, utilities provide shared primitives, and component CSS handles product-specific layout.

styles directory

agency-tokens.css

Warm editorial agency system: surfaces, gold, text scale, semantic colors, shadows, typography, layout, radii, spacing, z-index, legacy aliases, and error primitives.

agency-dark-overrides.css

Scoped .ag remaps for Tailwind-authored components so classes like bg-white and text-gray-900 resolve to agency tokens.

tokens.css

Talent and shared token layer for primary gold, text colors, warm backgrounds, borders, semantics, type sizes, spacing, radii, shadows, and transitions.

global.css

App-wide browser behavior: reset, base document styles, link defaults, focus rings, icons, skip link, container, buttons, tables, forms, and labels.

utilities.css

Lightweight layout utilities, explicit gold utility shims, font-display, dashboard keyframes, pholio-card, labels, scrollbar hiding, and agency textarea.

Component CSS

Co-located files own component-specific styling. Prefixes like ag-*, tp-*, ro-*, and cas-* keep selectors readable.

utilities.css

Shared helpers that sit after global.css.

Utilities include a small Tailwind-like layout layer, explicit gold shims, and shared dashboard presentation classes. They should be reused only when the behavior is genuinely cross-component.

Component CSS pattern

Use short prefixes and local ownership.

Co-located CSS files should use a BEM-like prefix tied to the component or domain, while agency-domain components should consume --ag-* tokens directly.
