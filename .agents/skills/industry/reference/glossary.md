# Glossary — Canonical Terminology & the Wrong→Right Map

The terminology auditor's dictionary. Use it to (a) define a term, (b) validate a proposed label/state name, (c) replace SaaS-generic wording with the real industry word. **In product, the industry term wins** unless a plain-English gloss is genuinely needed for a first-time talent — and even then, lead with the real term.

## How to use in an audit
For any user-facing string, state name, field label, or model name in Pholio, ask: *is this what the trade calls it?* If not, cite the file/string, give the correct term, and grade it (`P0` on a primary trust surface; `P1`/`P2` deeper in). Wrong vocabulary on a hero/agency surface is a P0 — it's the single fastest "built by outsiders" tell.

## Wrong → Right (the high-value corrections)

| Generic / wrong (avoid) | Correct industry term | Why it matters |
|---|---|---|
| Business card / profile card / model card | **Comp card** (composite / sed / zed card) | The card is a named, spec'd artifact; "business card" is an instant tell |
| Selfies / casual photos / quick pics | **Digitals** / **polaroids** | Digitals are a defined, ruled set (raw, dated, stats) — not selfies |
| Photo gallery / album (for the curated set) | **Book** / **portfolio** | The "book" is the model's curated best work; it has weight |
| Published photo / feature | **Tearsheet** ("tears") | Proof of real published work; a career currency |
| Category / tag / type (for the division) | **Board** / **division** | Bookers sit on boards; it's organizational, not a tag |
| Practice/free shoot | **Test** (often **TFP** — trade for prints) | "Testing" builds the book; a real verb |
| Job application / cover letter (to an agency) | **Submission** / **getting scouted** / **open call** | You submit *digitals*, not a résumé + cover letter |
| Interview (for meeting a client) | **Go-see** (general) / **casting** (specific job) / **call-back** | "Interview" is fine agency↔talent; wrong for client meetings |
| Reserved / pending (on the calendar) | **Option** (1st / 2nd) / **hold** | The booking calendar runs on options & holds, not "pending" |
| Unavailable (talent-set) | **Bookout** | Talent "books out" dates; precise term |
| Confirmed | **Booked** / **confirmed booking** | After option converts |
| Cancelled | **Released** (option) / **cancelled** (booking) | Releasing an option ≠ cancelling a confirmed job |
| Timesheet / receipt | **Voucher** | Signed on set; basis for billing & pay |
| Fee / usage fee (lumped) | **Day rate** + **usage / buyout** (separate) | Rate and usage are priced independently |
| Agency cut / platform fee | **Commission** (and **split** with mother agency) | Commission is the word; splits are structural |
| Sign-up bonus / payout (instant) | **Net pay** (after commission, **60–90 days**) | Pay is net and slow; "instant payout" is fiction |
| Stats / about (freeform) | **Measurements** (structured, dual-unit, dated) | Measurements are a typed, localized data model |

## Core term definitions (quick reference)

- **Mother agency / mother agent** — the agency that discovers, develops, and manages a model's overall career; places them with market agencies; stacks a smaller commission.
- **Booking / market / "daughter" agency** — represents the model in one market; a model has several, non-exclusively.
- **Board / division** — a roster grouping (Women, Men, New Faces, Curve, Commercial, Kids…). Bookers belong to one.
- **New face** — a model in early development; not yet fully bookable.
- **Comp card** — printed/PDF leave-behind: front image + name; back 3–5 images + stats. US 5.5×8.5″ / A5.
- **Digitals / polaroids** — raw, unretouched assessment images: headshot, ¾, full front, profile, back; minimal makeup; plain bg; form-fitting clothes; current (≤3 mo); with measurements.
- **Book / portfolio** — curated best work (tests, tears, campaigns).
- **Tearsheet** — page from a published editorial/campaign.
- **Test / TFP** — collaborative shoot to build the book; TFP = trade for prints.
- **Measurements / stats** — height, bust/chest, waist, hips, inseam, shoe (US/EU/UK), dress/suit, hair, eyes; gendered/division-specific; cm + inches.
- **Go-see** — general meeting with a client/casting director. **Casting** — meeting for a specific job. **Call-back** — second round. **Fitting** — garment fit. **Direct booking** — booked off the package without a casting.
- **Option** — a soft reservation of the model's dates by a client. **1st option** beats **2nd option**. Converts to **booked** or is **released**.
- **Hold** — client asks the model to keep dates open; not a booking; check with agency before taking conflicting work.
- **Bookout** — talent-declared unavailability (vacation, school, conflict).
- **Voucher** — signed on-set record of hours/rate/usage; basis for billing and pay.
- **Day rate** — pay for a day's work; plus half-day, fitting rate, travel, overtime.
- **Usage / buyout** — license to use the images: territory × media × duration × exclusivity. Buyout = one-time payment for a defined window.
- **Commission** — the agency's percentage (~15–20% from talent; often a parallel client service charge). **Split** — division of commission between mother & booking agencies (often 50/50).
- **Placement / stay** — sending a model to work a market (Paris/Tokyo/NYC stay); model apartments, travel, visas.
- **Call sheet** — the day's logistics (call time, location, crew, wardrobe).
- **Sample size** — the garment size shows/fit work are cut to; gates runway/fit.
- **Conflict / exclusivity** — restriction barring competing brands during a usage term.

## Regional / variation notes
- "Comp card" (US) ≈ "sed card"/"setcard" (Europe) ≈ "zed card." All correct.
- "Digitals" and "polaroids" are interchangeable; "Polaroid" is genericized.
- Units, garment sizing, and permit/trust rules vary by market — state the market when a term's meaning shifts.
