# Research brief: how the modeling / creative-talent industry operates today (2026)

Purpose: build an INDEPENDENT, primary-source-grounded model of the industry. It will be used to audit a
software product (Pholio: talent portfolios, comp cards, applying to agencies; agencies review submissions,
run casting/signing). You must NOT read the product's own code, docs, or skill files. Reason from first
principles and from what agencies, casting directors, industry bodies, regulators, printers, and working
models actually publish.

Rules of evidence
- Primary sources first: live agency websites (submission / "become a model" / "get scouted" / open call pages,
  board pages, model profile pages, FAQ, team pages), casting-director and casting-platform sites, industry
  bodies (BFMA, The Model Alliance, ICMF, Fashion Workers Act materials), regulators and statutes (NY DOL, NY
  Labor Law Art. 11 / Fashion Workers Act eff. 2025, CA Labor Code §1700-1704 incl. Krekorian Talent Scam
  Prevention Act, CA Coogan, UK child performance licensing), comp-card printers, agency-software vendors
  (Syngency, Netwalk, Mediaslide, Portfoliopad, Agencypin), models.com. Secondary sources (coaching blogs,
  r/modeling, trade press like BoF/WWD/Models.com articles) are allowed only to corroborate or to capture how
  working models talk; label them as secondary.
- Quote verbatim wherever the wording matters (labels, field names, instructions). Record the URL and the
  date accessed. If a page 403s or fails through the proxy, try another agency; note failures.
- Distinguish: universal norm / majority convention / regional (US vs UK/EU vs Asia) / single-agency quirk /
  contested. Never present one agency's wording as the industry's. Count how many sources use a term.
- Note when a widely repeated "rule" (e.g. exact height cutoffs) is a fashion-board gate rather than an
  industry-wide fact. Note scam-coded language that legitimate players avoid.
- Where evidence is thin, say so explicitly. Do not fill gaps from memory without labelling it as such.

Deliverable: a markdown file at the path you are given, structured as:
1. Summary of the mental model (how this part of the industry actually works, in the practitioner's own frame).
2. Vocabulary table: term | meaning | who uses it (agency/talent/casting/regulator) | region | evidence count |
   verbatim example + URL. Include WRONG or outsider terms practitioners would flinch at, and why.
3. Workflow / state model as practitioners describe it (who acts, what is reversible, what it obligates).
4. Data conventions (fields, units, order, what is shown/withheld, recency).
5. Trust & legitimacy signals: what legitimate players say and refuse to say; what talent are warned about.
6. Open questions / contested points, with the evidence on each side.
7. Source list with URLs, access date, and what each was used for.
Aim for depth over breadth of prose: 250-500 lines, dense, evidence-heavy. Work with WebSearch and WebFetch
(or curl through the configured proxy if needed). Sample at least 12 distinct primary sources.
