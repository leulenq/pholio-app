# Presentation IA — three surfaces, three content tiers

## The standard (owner's words, operationalized)
- Glance at an agency in Market → understand what applying involves.
- Open the entry → the complete brief, scannable.
- Enter Apply → zero surprise requirements later.
Everything we verified but a talent doesn't need at a given moment stays OUT of that moment.

## Tier 1 — Market glance (directory card/row)
Budget: ≤6 data points. NO prose paragraphs.
1. Name + market ("Muse Management · New York")
2. Registered badge (NYDOL cert exists) — icon + "Registered" on hover/detail only
3. Apply method chip: "Online form" | "Email" | "Form or email" | "Event form"
4. Prep summary in one compact line: "4 photos · measurements" / "3 photos + 2 videos optional"
5. Hard gate chip ONLY when the form enforces it or copy states it: "Women only" (Elite), "18+" (Wilhelmina). Not preferences.
6. Heads-up dot (count folded to one indicator) when ≥1 HIGH caution exists.
Footer microcopy: "Checked Aug 19, 2026".
NOT in Tier 1: file sizes, formats, channel counts, contradictions text, legal, minors detail, open-call times.

## Tier 2 — Agency brief (expanded view)
Fixed section order across ALL agencies (scannability = consistency):
1. Header: name, market, Registered · NY DOL badge with cert number, "Checked Aug 19, 2026", official apply link (the verified one).
2. "How you apply" — canonical channel as one sentence; other channels only if a talent should know (State's two-form situation gets 2 sentences + a "differences" inline table of the 3 facts that differ; Ford's Paris quirk = one line, NYC talent barely cares).
3. "Get ready" — three fixed groups:
   • Photos — slot list with canonical names, then shooting rules as ≤5 bullets (dedup: each rule once).
   • Videos — only if relevant (ONE, else omit group entirely — absent group is information).
   • Your details — what fields they ask (summarized: "contact info, measurements (bust/waist/hips), Instagram"), units guidance when the form doesn't say.
4. "Who they're looking for" — eligibility as published, preferences marked as preferences ("They prefer 5'9"+ — and say they represent all sizes"), divisions honesty ("No way to pick Curve on the form; the agency routes you").
5. "Under 18?" — ALWAYS present, one short paragraph of the actual truth, action-oriented.
6. "After you submit" — response policy or the honest default ("Most applicants won't hear back — that's normal here, not a mistake.")
7. "Heads-ups" — max 3 items, HIGH severity always, MEDIUM only if talent-actionable. Phrased as guidance, never as "contradiction detected".
8. "Fine print" — collapsed by default: legal regime notes that matter (Snapcast license), retention, address, phone.
NOT in Tier 2: byte-exact caps per slot, accept strings, field-by-field lists, DOM trivia, honeypots, evidence, research labels.

## Tier 3 — Apply / preflight
Mechanical, moment-of-need:
- Per-photo checklist rows: slot name, format ("JPG or PNG"), size ("under 600 KB" / "no stated limit — we'll keep yours reasonable"), auto-convert note for HEIC per channel.
- Field preview: the actual fields they'll face, in their order, with unit hints.
- Blocking callouts at the exact step: "This form has no email field — double-check your phone number" (FWB); "You'll need a parent to email the agency first" (guardian steps); "Bring-your-own YouTube link (optional)" (ONE).
- Open-call info with the honesty line ("Thursdays 3–4 PM — the agency doesn't publish the address; confirm before going").

## Style guide (enforced across all tiers)
- Sentence case everywhere. Canonical shot names: "Close-up", "Full length", "Profile", "Waist up", "3/4 profile", "Personality photo". Units: "3 MB", "600 KB", "5'9\"".
- One requirement = one appearance per surface. A rule shown in Photos never repeats in Eligibility.
- Unknowns: "The agency doesn't say." — never blank, never "unknown", never "not published".
- Preferences: "They prefer…" — never rendered as requirements.
- Cautions: verb-first practical guidance ("Double-check…", "If you're 14–15, contact…").
- Never: research labels (FACT/OBSERVED), sourceLabel text, machine names (uploadClose), agency typos (correct in canon; verbatim lives in the registry layer), counts of database rows, "verified"/"approved" language about the agency relationship. "Checked <date>" is the only trust stamp.
- Voice: second person, calm, concrete. No exclamation marks except quoted agency copy (which we avoid in UI anyway).
